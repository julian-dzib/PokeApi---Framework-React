# PokeApi---Framework-React

Proyecto que consume el servicio de [PokeApi](https://pokeapi.co/) usando **React** y **Next.js**, implementando:

- Consumo de API de Pokémon
- Paginación
- Buscador de Pokemones
- Uso de Hooks (`useState`, `useEffect`)
- Buenas prácticas de componentes
- UI responsiva con Tailwind CSS

---

1. **Clonar el repositorio:**

```bash
